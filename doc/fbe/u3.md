# FOAM U3 By Example

<term term="U3"></term> is FOAM's next-generation reactive UI framework, replacing U2. U3 simplifies view development by eliminating lifecycle states, providing a cleaner API, and offering better performance through optimized DOM operations.

<toc></toc>

## Overview

### U3 vs U2

| Feature | U2 | U3 |
|---------|----|----|
| Lifecycle states | INITIAL → OUTPUT → LOADED → UNLOADED | None (simpler) |
| Element creation | `this.E()` | `this.E()` |
| Adding content | `add()`, `start()`/`end()` | Same, plus improvements |
| CSS scoping | `^` prefix | Same |
| Borders | Use `init()` | Use `render()` |
| State management | Slots | Same, with enhancements |

### Key Concepts

| Concept | Description |
|---------|-------------|
| **Element** | Base class for all UI components |
| **Slot** | Reactive value container for data binding |
| **CSS Scoping** | Automatic class prefixing with `^` |
| **Borders** | Wrapper components that surround content |
| **ViewSpec** | Specification for deferred view creation |

## Creating Elements

### The E() Function

`E()` creates a new Element. With no arguments, it creates a `<div>`. Pass a tag name for other elements.

<example id="creating-elements">
// Create elements using E()
let e = this.E();           // Creates a <div>
let span = this.E('span');  // Creates a <span>

// Add content and build hierarchy
e.add('Hello, World!');
e.add(span.add('inside span'));

add(e);
</example>

### The add() Method

`add()` appends content to an element. It accepts multiple argument types:

| Argument Type | Result |
|---------------|--------|
| String | Text node |
| Number | Text node |
| Element | Child element |
| Array | Each item added |
| Slot | Reactive binding |
| Function | Called, result added |
| Promise | Placeholder until resolved |
| `{class: '...'}` | ViewSpec, creates view |

<example id="add-method">
let e = this.E();

// Multiple types in one call
e.add(
  'Text ',
  42,
  this.E('b').add('bold'),
  ['a', 'b', 'c'],  // Array items added separately
  () => 'from function'
);

add(e);
</example>

## Building Hierarchies

### start() and end()

`start()` creates a child element and makes it the current context. `end()` returns to the parent. This enables fluent DOM construction.

<example id="start-end">
add(
  this.E()
    .start('div').addClass('container')
      .start('h1').add('Title').end()
      .start('p').add('Paragraph text').end()
      .start('ul')
        .start('li').add('Item 1').end()
        .start('li').add('Item 2').end()
        .start('li').add('Item 3').end()
      .end()
    .end()
);
</example>

### tag() Shortcut

`tag()` is equivalent to `start().end()` — creates and closes an element in one call.

<example id="tag-shortcut">
add(
  this.E()
    .tag('hr')
    .tag('br')
    .tag('input', { type: 'text', placeholder: 'Enter name' })
);
</example>

### start() with ViewSpecs

Pass a ViewSpec or class to `start()` to create complex views.

<example id="start-viewspec">
foam.CLASS({
  name: 'MyButton',
  extends: 'foam.u2.Element',
  properties: [
    { name: 'label', value: 'Click Me' }
  ],
  methods: [
    function render() {
      this.addClass()
        .start('button')
          .add(this.label)
          .on('click', () => console.log('Clicked!'))
        .end();
    }
  ]
});

add(
  this.E()
    .start(MyButton, { label: 'Custom Label' }).end()
    .start({ class: 'MyButton', label: 'Via ViewSpec' }).end()
);
</example>

## Attributes and Styles

### Setting Attributes

Use `attrs()` for HTML attributes.

<example id="attributes">
add(
  this.E('input').attrs({
    type: 'text',
    placeholder: 'Enter value',
    maxlength: 50,
    disabled: false
  })
);

add(
  this.E('a').attrs({
    href: 'https://example.com',
    target: '_blank'
  }).add('Link')
);
</example>

### Inline Styles

Use `style()` for inline CSS styles.

<example id="inline-styles">
add(
  this.E()
    .style({
      padding: '20px',
      backgroundColor: '#f0f0f0',
      border: '1px solid #ccc',
      borderRadius: '8px'
    })
    .add('Styled box')
);
</example>

### Classes

Use `addClass()`, `removeClass()`, and `enableClass()` for CSS classes.

<example id="classes">
foam.CLASS({
  name: 'ClassDemo',
  extends: 'foam.u2.Element',

  css: `
    ^highlight { background: yellow; }
    ^error { color: red; font-weight: bold; }
  `,

  properties: [
    { class: 'Boolean', name: 'isError' }
  ],

  methods: [
    function render() {
      this
        .addClass()  // Adds the class's default class
        .addClass(this.myClass('highlight'))  // Adds scoped class
        .enableClass(this.myClass('error'), this.isError$)  // Conditional class
        .add('Toggle error state')
        .tag('br')
        .startContext({ data: this })
          .tag(this.IS_ERROR.__)
        .endContext();
    }
  ]
});

add(ClassDemo.create());
</example>

## CSS in U3

### Scoped CSS with ^

The `^` prefix is replaced with a unique class name for the component, preventing style conflicts.

<example id="scoped-css">
foam.CLASS({
  name: 'StyledCard',
  extends: 'foam.u2.Element',

  css: `
    ^ {
      padding: 16px;
      margin: 8px;
      border: 1px solid #ddd;
      border-radius: 4px;
    }
    ^title {
      font-size: 18px;
      font-weight: bold;
      margin-bottom: 8px;
    }
    ^content {
      color: #666;
    }
    ^:hover {
      box-shadow: 0 2px 8px rgba(0,0,0,0.1);
    }
  `,

  properties: ['title', 'content'],

  methods: [
    function render() {
      this.addClass()
        .start().addClass(this.myClass('title')).add(this.title).end()
        .start().addClass(this.myClass('content')).add(this.content).end();
    }
  ]
});

add(StyledCard.create({ title: 'Card Title', content: 'Card content goes here.' }));
</example>

### myClass() Helper

`myClass('name')` returns the scoped class name. Use it in JavaScript when you need the full class name.

<example id="myclass">
foam.CLASS({
  name: 'MyClassDemo',
  extends: 'foam.u2.Element',

  css: `
    ^active { background: green; color: white; }
    ^inactive { background: gray; color: white; }
  `,

  properties: [
    { class: 'Boolean', name: 'isActive', value: true }
  ],

  methods: [
    function render() {
      // Dynamic class based on state
      this.addClass(this.isActive$.map(active =>
        this.myClass(active ? 'active' : 'inactive')
      )).add('Status indicator');
    }
  ]
});

add(MyClassDemo.create());
</example>

## Reactive Data Binding

### Slots

<term term="Slots"></term> are reactive value containers. When a slot's value changes, all dependent UI updates automatically.

<example id="slots-basic">
foam.CLASS({
  name: 'CounterDemo',
  extends: 'foam.u2.Element',

  properties: [
    { class: 'Int', name: 'count', value: 0 }
  ],

  methods: [
    function render() {
      this
        .add('Count: ')
        .add(this.count$)  // Reactively updates
        .tag('br')
        .start('button')
          .add('+')
          .on('click', () => this.count++)
        .end()
        .start('button')
          .add('-')
          .on('click', () => this.count--)
        .end();
    }
  ]
});

add(CounterDemo.create());
</example>

### Slot Mapping

Use `slot.map()` to transform values reactively.

<example id="slot-mapping">
foam.CLASS({
  name: 'MappingDemo',
  extends: 'foam.u2.Element',

  properties: [
    { class: 'Int', name: 'celsius', value: 20 }
  ],

  methods: [
    function render() {
      let fahrenheit$ = this.celsius$.map(c => (c * 9/5) + 32);

      this
        .start('input')
          .attrs({ type: 'range', min: -20, max: 50 })
          .attrSlot('value').linkFrom(this.celsius$)
        .end()
        .tag('br')
        .add('Celsius: ', this.celsius$)
        .tag('br')
        .add('Fahrenheit: ', fahrenheit$);
    }
  ]
});

add(MappingDemo.create());
</example>

### Dynamic Content with Slots

Add slots directly to `add()` for content that updates when the slot changes.

<example id="dynamic-content">
foam.CLASS({
  name: 'DynamicDemo',
  extends: 'foam.u2.Element',

  properties: [
    {
      class: 'String',
      name: 'color',
      value: 'red',
      view: {
        class: 'foam.u2.view.ChoiceView',
        choices: ['red', 'green', 'blue', 'orange']
      }
    }
  ],

  methods: [
    function render() {
      this
        .startContext({ data: this })
          .tag(this.COLOR.__)
        .endContext()
        .tag('br')
        .start()
          .style({
            color: this.color$,
            fontSize: '24px',
            fontWeight: 'bold'
          })
          .add('Colored Text')
        .end();
    }
  ]
});

add(DynamicDemo.create());
</example>

## Event Handling

### on() Method

`on()` attaches DOM event listeners.

<example id="events">
foam.CLASS({
  name: 'EventDemo',
  extends: 'foam.u2.Element',

  css: `
    ^box {
      width: 200px;
      height: 100px;
      background: #eee;
      display: flex;
      align-items: center;
      justify-content: center;
      cursor: pointer;
      user-select: none;
    }
    ^box:hover { background: #ddd; }
  `,

  properties: [
    { name: 'message', value: 'Interact with me!' }
  ],

  methods: [
    function render() {
      this.addClass()
        .start().addClass(this.myClass('box'))
          .on('click', () => this.message = 'Clicked!')
          .on('mouseenter', () => this.message = 'Mouse entered')
          .on('mouseleave', () => this.message = 'Mouse left')
          .add(this.message$)
        .end();
    }
  ]
});

add(EventDemo.create());
</example>

### Keyboard Shortcuts

Use `onKey()` or <term term="KeyboardShortcuts"></term> for keyboard handling.

<example id="keyboard">
foam.CLASS({
  name: 'KeyboardDemo',
  extends: 'foam.u2.Element',

  imports: ['ctrl'],

  properties: [
    { name: 'lastKey', value: 'Press a key...' }
  ],

  methods: [
    function render() {
      this
        .on('keydown', (e) => {
          this.lastKey = `Key: ${e.key} (code: ${e.code})`;
          if (e.key === 'Escape') this.lastKey = 'Escape pressed!';
        })
        .attrs({ tabindex: 0 })  // Make focusable
        .style({ padding: '20px', border: '1px solid #ccc', outline: 'none' })
        .add(this.lastKey$)
        .tag('br')
        .add('(Click to focus, then press keys)');
    }
  ]
});

add(KeyboardDemo.create());
</example>

## Borders

<term term="Borders"></term> are wrapper components that surround their content. They're useful for cards, modals, accordions, and any container with decoration.

<example id="borders">
foam.CLASS({
  name: 'CardBorder',
  extends: 'foam.u2.Element',

  css: `
    ^ {
      border: 2px solid #333;
      border-radius: 8px;
      margin: 10px;
      overflow: hidden;
    }
    ^header {
      background: #333;
      color: white;
      padding: 10px;
      font-weight: bold;
    }
    ^body {
      padding: 15px;
    }
  `,

  properties: ['title'],

  methods: [
    function render() {
      this.addClass()
        .start().addClass(this.myClass('header'))
          .add(this.title)
        .end()
        .start().addClass(this.myClass('body'))
          .add(this.childNodes)  // Renders children here
        .end();
    }
  ]
});

add(
  CardBorder.create({ title: 'My Card' })
    .add('This content is inside the card body.')
    .tag('br')
    .add('Multiple elements work too!')
);
</example>

## Conditional Rendering

### show() and hide()

Control visibility with `show()` based on a slot or value.

<example id="show-hide">
foam.CLASS({
  name: 'VisibilityDemo',
  extends: 'foam.u2.Element',

  properties: [
    { class: 'Boolean', name: 'showDetails', value: false }
  ],

  methods: [
    function render() {
      this
        .start('button')
          .add(this.showDetails$.map(v => v ? 'Hide' : 'Show'))
          .on('click', () => this.showDetails = !this.showDetails)
        .end()
        .start()
          .show(this.showDetails$)
          .style({ padding: '10px', background: '#f0f0f0', marginTop: '10px' })
          .add('These are the hidden details!')
        .end();
    }
  ]
});

add(VisibilityDemo.create());
</example>

### call() and callIf()

Execute functions conditionally in fluent chains.

<example id="call-if">
foam.CLASS({
  name: 'CallIfDemo',
  extends: 'foam.u2.Element',

  properties: [
    { class: 'Boolean', name: 'isAdmin', value: true }
  ],

  methods: [
    function render() {
      this
        .add('User Panel')
        .callIf(this.isAdmin, function() {
          this.tag('br')
            .start()
              .style({ color: 'red', fontWeight: 'bold' })
              .add('Admin Controls Visible')
            .end();
        })
        .tag('br')
        .startContext({ data: this })
          .tag(this.IS_ADMIN.__)
        .endContext();
    }
  ]
});

add(CallIfDemo.create());
</example>

### forEach()

Iterate over arrays in fluent chains.

<example id="foreach">
foam.CLASS({
  name: 'ForEachDemo',
  extends: 'foam.u2.Element',

  properties: [
    {
      name: 'items',
      factory: () => ['Apple', 'Banana', 'Cherry', 'Date']
    }
  ],

  methods: [
    function render() {
      this
        .start('ul')
          .forEach(this.items, function(item) {
            this.start('li').add(item).end();
          })
        .end();
    }
  ]
});

add(ForEachDemo.create());
</example>

## Animations

U3 supports CSS transitions and animations. Use `style()` with slots for reactive animations.

<example id="animations">
foam.CLASS({
  name: 'AnimationDemo',
  extends: 'foam.u2.Element',

  css: `
    ^box {
      width: 100px;
      height: 100px;
      background: blue;
      transition: all 0.3s ease;
      display: flex;
      align-items: center;
      justify-content: center;
      color: white;
      cursor: pointer;
    }
    ^box:hover {
      transform: scale(1.1);
      background: darkblue;
    }
    ^animated {
      animation: pulse 1s infinite;
    }
    @keyframes pulse {
      0%, 100% { opacity: 1; }
      50% { opacity: 0.5; }
    }
  `,

  properties: [
    { class: 'Boolean', name: 'isPulsing', value: false }
  ],

  methods: [
    function render() {
      this.addClass()
        .start()
          .addClass(this.myClass('box'))
          .enableClass(this.myClass('animated'), this.isPulsing$)
          .on('click', () => this.isPulsing = !this.isPulsing)
          .add('Click me')
        .end();
    }
  ]
});

add(AnimationDemo.create());
</example>

## Views and Data

### data Property

Views bind to a `data` property. Changes to data reflect in the view automatically.

<example id="data-binding">
foam.CLASS({
  name: 'PersonView',
  extends: 'foam.u2.View',  // Note: extends View, not Element

  css: `
    ^ { padding: 10px; border: 1px solid #ccc; margin: 5px; }
    ^label { font-weight: bold; }
  `,

  methods: [
    function render() {
      // this.data is the bound object
      this.addClass()
        .start().addClass(this.myClass('label')).add('Name: ').end()
        .add(this.data$.dot('name'))
        .tag('br')
        .start().addClass(this.myClass('label')).add('Age: ').end()
        .add(this.data$.dot('age'));
    }
  ]
});

foam.CLASS({
  name: 'Person',
  properties: ['name', 'age']
});

let person = Person.create({ name: 'John', age: 30 });
add(PersonView.create({ data: person }));

// Changes reflect automatically
setTimeout(() => { person.name = 'Jane'; person.age = 25; }, 2000);
</example>

## Context and Exports

### Exporting Values

Use `exports` to make values available to child components via dependency injection.

<example id="exports">
foam.CLASS({
  name: 'ThemeProvider',
  extends: 'foam.u2.Element',

  exports: ['primaryColor'],

  properties: [
    { name: 'primaryColor', value: '#007bff' }
  ],

  methods: [
    function render() {
      this
        .add('Theme Provider')
        .tag('br')
        .tag(ThemedButton)
        .tag(ThemedButton);
    }
  ]
});

foam.CLASS({
  name: 'ThemedButton',
  extends: 'foam.u2.Element',

  imports: ['primaryColor'],

  methods: [
    function render() {
      this
        .start('button')
          .style({
            background: this.primaryColor,
            color: 'white',
            border: 'none',
            padding: '8px 16px',
            margin: '4px'
          })
          .add('Themed Button')
        .end();
    }
  ]
});

add(ThemeProvider.create());
</example>

## Summary

### Element Methods Quick Reference

| Method | Description |
|--------|-------------|
| `add(content)` | Add content (text, elements, slots) |
| `start(tag/class)` | Create child, enter context |
| `end()` | Exit child context |
| `tag(tag, attrs)` | Create self-closing element |
| `addClass(class)` | Add CSS class |
| `removeClass(class)` | Remove CSS class |
| `enableClass(class, slot)` | Conditional CSS class |
| `attrs(obj)` | Set HTML attributes |
| `style(obj)` | Set inline styles |
| `on(event, handler)` | Add event listener |
| `show(slot)` | Conditional visibility |
| `call(fn)` | Execute function in chain |
| `callIf(cond, fn)` | Conditional execution |
| `forEach(arr, fn)` | Iterate in chain |

### Best Practices

1. **Use scoped CSS** — Always use `^` prefix for component styles
2. **Leverage slots** — Bind data reactively instead of manual updates
3. **Prefer composition** — Build complex UIs from simple components
4. **Use ViewSpecs** — Let FOAM manage view lifecycle
5. **Keep render() pure** — Avoid side effects in render methods
