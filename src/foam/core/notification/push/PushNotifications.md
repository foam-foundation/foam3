# Push Notifications

## Web Push

Web Push is supported by the WebPushService.  The enable web push you need to configure a VAPID key pair

`$ npx web-push generate-vapid-keys --json`

Then in your app/deployment services.jrl configure the WebPushService

```
p({
  "class":"foam.core.boot.CSpec",
  "name":"WebPushService",
  "lazy":true,
  "serve":false,
  "authenticate":false,
  "service":{
    "class":"foam.core.notification.push.WebPushService",
    "supportEmail": "some-support@email",
    "publicKey": "public key generated by web-push",
    "privateKey": "private key generated by web-push"
  }
})
```

## APNS (Apple) Push

APNS push is supported by he APNSPushService in core.

1. To setup APNS push notification support, you need to first register your app with Apple <a href="https://developer.apple.com/documentation/usernotifications/registering-your-app-with-apns"/>
2. Then you need to obtain an SSL client certificate for authenticated to APNS from core. <a href="https://developer.apple.com/documentation/usernotifications/establishing-a-certificate-based-connection-to-apns"/>
3. 

You then need to put your certificate and the associated private key into a .p12 file. If you followed instructions on the above link, you can export a .p12 from the Keychain Access app on macOS by finding the certificate, right clicking and selecting "export"

4. Convert the .p12 file to base64 using the shell `$ base64 -b 70 < push-credentials.p12 > push-credentials.p12.txt`
5. Save your apns credentials into a credentials.jrl file in your app/deployment 
```
p({
  "class": "foam.core.notification.push.APNSCredential",
  "id": "apns-sandbox-creds",
  "host": "api.sandbox.push.apple.com",
  "appBundleId": "my.app.bundle.id",
  "p12Password": "password",
  "p12Base64": """
  RUtx+68Ctaqhaa5vFI7iUPG2IXo7hhPgSqFScdY02Rm9k4cQmeIaL3bfi2U3HwXi4msS+v
  uIf4roiUOg3Us8m8RgHOkZr/GAbxDRqBS8DnD5PXbAp1VscBvvxI1cOG3bkd3ept5+TAQ/
  jiVUqIsD0RhKdrpJ3UZ0naD...
"""
})
```

6. Finally configure the APNSpushService to use the newly created credentials 
```
p({
  "class":"foam.core.boot.CSpec",
  "name":"APNSpushService",
  "lazy":true,
  "serve":false,
  "service":{
    "class":"foam.core.notification.push.APNSPushService",
    "apnsCredentialId": "apns-sandbox-creds"
  }
})
```
